# Product

## Register

product

## Users

People looking for rental housing in Italy, using their own Windows computer and a local browser. They compare listings, maintain search preferences and review AI suggestions before acting.

## Product Purpose

Collect rental listings from configured sources, preserve an understandable archive and help the user compare homes. Keep scans manual and personal accounts, credentials and history local.

## Brand Personality

Calm, practical, readable. Italian labels describe user actions rather than implementation files. Preserve the established sage and warm-neutral House Finder interface.

## Anti-references

No marketing dashboard redesign, decorative metrics, card grids for every setting, automatic account activation or invisible changes to search preferences.

## Design Principles

- Extend the existing components and navigation rather than replacing them.
- Separate connection setup, task routing and diagnostics.
- Show which listing context is sent to the selected AI connection.
- Keep proposals distinct from confirmed actions.
- Make busy, failed and unavailable states actionable without exposing secrets.

## Accessibility & Inclusion

Use existing labelled controls, keyboard navigation, visible focus, semantic buttons and tabs. Preserve light/dark themes, self-hosted fonts and mobile layouts. Respect reduced motion and communicate states with text as well as color.
