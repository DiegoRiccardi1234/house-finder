# Credits — images

The README screenshots (`docs/*.png`) are generated by `npm run docs:shots` from the demo dataset
`state/listings.demo.json` — made-up listings, no real data.

The apartment photos shown on the cards (`ui/public/demo/*.jpg`) come from
[Unsplash](https://unsplash.com) under the [Unsplash License](https://unsplash.com/license)
(commercial use allowed, attribution not required — credited anyway), resized to 600×400.
Source IDs are listed in the table above.

No real listing photo is versioned in this repository: thumbnails downloaded during a run live in
`state/thumbs/`, which is gitignored.
